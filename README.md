## Data science case studies

Each runs the full cycle in notebooks (data audit and EDA, out-of-time validation against baselines and a tuned challenger, calibration, SHAP, the business decision and a model card), then ships a Power BI report with its own design. Every published number is reproduced and asserted in code; unit tests run in CI.

## How I work

- **Start from the decision.** Every model answers who to contact, what to offer, or where to open.
- **Prove it against a holdout.** Campaigns run as A/B tests; results are judged on incremental lift.
- **Define it once.** KPIs live in one governed semantic layer that reports, models and AI assistants all share.
